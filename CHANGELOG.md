## [1.0.0] - 2026-05-03

### Added
- 70 opsi perbaikan printer sharing untuk Windows 10/11/Server
- Support Windows 11 24H2, 25H2, 26H2 dan ARM64 (Snapdragon)
- Support Windows Server 2019, 2022, 2025
- AllFix: 42 langkah perbaikan otomatis dalam satu perintah
- Jalur Extreme khusus Windows 11 Build 26000+
- Silent Nuke mode (tanpa interaksi, auto restart)
- Sistem bantuan interaktif (`?`, `? <nomor>`, `? all`)
- Dokumentasi offline HTML lengkap
- Installer Inno Setup dengan code signing certificate
- Script otomasi compile PS1 ke EXE
- Diagnostik sistem (Spooler, RPC, Firewall, Network Profile)
- Remote printer management (Ping, Scan, Remote Spooler Reset)
- PrintBRM backup/restore
- Spooler Watchdog scheduled task
- System Restore Point integration
- Log perbaikan dengan export ke HTML
